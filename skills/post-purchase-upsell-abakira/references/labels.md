# Admin labels in all six languages

The admin follows the language of the merchant's own Shopify admin — one of six:
English, French, Spanish, German, Portuguese, Dutch. This skill and every other reference
file use the **English** label. If a merchant reports seeing something that
doesn't match, look it up here before assuming the menu changed.
